# Guía de Contribución

¡Gracias por tu interés en aportar rigor y propuestas a este programa! Al tratarse de un proyecto basado en evidencia, cualquier aportación debe cumplir con tres criterios metodológicos:

1. **Sustento Empírico:** Toda medida propuesta debe venir acompañada de referencias a estudios económicos, informes de organismos independientes (AIReF, OCDE, FMI, Banco de España) o datos estadísticos verificables.
2. **Viabilidad Presupuestaria:** Si una propuesta implica gasto público, debe indicar explícitamente su fuente de financiación (mediante *Spending Review*, reasignación de partidas o ensanchamiento de bases fiscales).
3. **Respeto Constitucional:** Las propuestas deben encuadrarse dentro del marco jurídico y competencial vigente o especificar claramente la reforma legal necesaria.

### Pasos para colaborar:
1. **Abre un Issue:** Si quieres debatir un cambio de enfoque o proponer una nueva medida, abre una incidencia (*Issue*) detallando la justificación técnica.
2. **Envía un Pull Request (PR):** Si vas a modificar directamente el texto del programa, haz un fork del repositorio, edita el archivo correspondiente y abre un PR explicando claramente el fundamento económico o técnico del cambio.
